# HOW MANY ASSERTIONS EACH LAYER MUST STILL MAKE.
#
# A layer that stops asserting things does not go red. `_verdict()` refuses a green that asserted NOTHING,
# and between zero and everything there was no floor at all: the widest layer here makes 112 assertions and
# could have fallen to one and still printed PASS. Measured across three consecutive sweeps of 91 layers,
# the only counts that moved were the five layers edited between them, and each moved by exactly the number
# of assertions added or withdrawn. The count is a faithful signal, so it is held.
#
# THE FLOOR IS THE OBSERVED COUNT, NOT A MARGIN BELOW IT. A margin would absorb the first real loss silently,
# which is the whole failure being guarded against. Lowering a row is a deliberate act and the commit that
# does it has to say which assertion went and why; a row is never lowered to clear a red.
#
# JUDGED ONLY ON A FULL CONFIGURED SWEEP with this exact stand-down set. A subset run has no opinion about
# layers it did not run, and a different stand-down set means different assertions were reached, so the
# gate says it did not judge rather than inventing a verdict. Regenerate after a deliberate change:
#   tools/assert_floors.sh --write <log-dir>
#
# THE POPULATION, STATED, because a number of rows against a suite of 113 is a gap and a gap nobody names
# reads as coverage. 108 of 113 rows are held, under TWO rules: 91 report "(N asserted)" from `_verdict()`,
# and 17 have no `_check` to count and print one PASS line per claim instead. The second rule is what
# brings in the four largest bodies of assertions in the suite, none of which anything held before:
# `sim` 526, `stress` 447, `power_water` 203, `worldgen` 147. Each row carries the rule that produced it.
#
# FIVE ROWS REMAIN UNREACHABLE and are not exempted: check_capture_manifest, check_prose, check_score,
# check_water_audio and measure_player each print a verdict in a shape neither rule counts. Holding them
# needs a third rule or a change to what they print, and neither is written. Re-derive the gap with:
#   for f in <log-dir>/*.log; do grep -qE '\([0-9]+ asserted\)|^[[:space:]]*(PASS|ok|OK)[: ]' "$f" \
#     || basename "$f"; done
