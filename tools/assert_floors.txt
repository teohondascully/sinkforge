# HOW MANY ASSERTIONS EACH LAYER MUST STILL MAKE.
#
# A layer that stops asserting things does not go red. `_verdict()` refuses a green that asserted NOTHING,
# and between zero and everything there was no floor at all: the widest layer here makes several hundred
# assertions and could have fallen to one and still printed PASS. Measured across three consecutive sweeps
# of 91 layers, the only counts that moved were the five layers edited between them, and each moved by
# exactly the number of assertions added or withdrawn. The count is a faithful signal, so it is held.
#
# THE FLOOR IS THE OBSERVED COUNT, NOT A MARGIN BELOW IT. A margin would absorb the first real loss silently,
# which is the whole failure being guarded against. Lowering a row is a deliberate act and the commit that
# does it has to say which assertion went and why; a row is never lowered to clear a red.
#
# JUDGED ONLY ON A FULL CONFIGURED SWEEP with this exact stand-down set. A subset run has no opinion about
# layers it did not run, and a different stand-down set means different assertions were reached, so the
# gate says it did not judge rather than inventing a verdict. Regenerate after a deliberate change:
#   tools/assert_floors.sh --write <log-dir>
#
# THE POPULATION, STATED, because a number of rows against a suite of 114 is a gap and a gap nobody names
# reads as coverage. ALL 114 of 114 rows are held, under THREE rules: 96 report "(N asserted)" -- 92 from
# `_verdict()` and four that were taught to print it, below -- 17 have no `_check` to count and print one
# PASS line per claim instead, and one writes its verdict at the end of the line. The second rule is what
# brings in the four largest bodies of assertions in the suite, none of which anything held before:
# `sim` 526, `stress` 447, `power_water` 203, `worldgen` 147. Each row carries the rule that produced it,
# and a floor set under one rule is never compared against a count taken under another.
#
# A THIRD RULE BROUGHT IN ONE OF THE FIVE. `measure_player` writes its verdict at the END of the line,
# "run speed px/s: measured 150.0, intended 150.0 (+/-6%)  OK", which neither of the first two rules can
# see. Checked against all 113 logs of a full sweep before it was added: five layers matched neither rule,
# and the trailing-OK pattern counts 3 for `measure_player` and 0 for the other four, so it holds exactly
# one new row and moves nothing that was already held.
#
# TWO OF THOSE FOUR WERE CLOSED AT THE SOURCE, which was the only way to close them: no pattern can count
# assertions a layer never enumerated. `check_score` and `check_water_audio` counted their FAILURES only,
# and a failure count of zero is what both a layer that checked twenty-one things and a layer that checked
# nothing report. Each gained a `_claim(ok, msg)` that tallies the attempt and returns the result, so the
# `continue` paths still work, and each now prints "(N asserted)" on the passing path and
# "N FAILURE(S) of M asserted" on the failing one — so a red still reports its count, which is the
# property whose absence made this gate accuse `check_grapple_reads` of a drop it had not made.
#
# The descent walk's per-step checks in `check_score` were collected rather than claimed per step: one
# claim per step would tie the layer's count to the number of steps sampled, so re-sampling the descent
# would read as assertions appearing or going missing. Every violation is still reported, in one message.
#
# AND THE LAST TWO WERE CLOSED THE SAME WAY, at the source rather than with a fourth pattern. Both are
# shell layers, so the convention is simply that a shell layer prints the same two sentences a GDScript
# one does: "(N asserted)" when it passes and "N FAILURE(S) of M asserted" when it does not.
#
# `check_capture_manifest` needed a witness before it could be counted at all. Its claim is that the
# tracked manifest equals a freshly regenerated one, and a claim of SAMENESS is satisfied by a build where
# nothing happened: had the scan found no captures, `diff` would have been quiet and the layer would have
# reported the archive correctly described while describing nothing. The population is asserted first —
# it currently describes 52 captures — so the comparison is a comparison of something. Three claims.
#
# `check_prose` counts the files it actually TESTED, which is not the files it opened. Its wide sweep with
# no word list opens every tracked file and tests nothing, and that population is excluded from the count
# for the same reason the script's own last line refuses to call it clean. 444 = 60 narrow + 22 positional
# + 362 wide.
#
# Being off `check_base.gd` was never why any of them were unreachable: 19 registered layers are off it
# and 15 were held before any of this work. The boundary was always the dialect a layer speaks.
#

#     || basename "$f"; done
